# yam-cliamp 🦙⚡

Нативная интеграция **Яндекс Музыки** с терминальным плеером **cliamp**.

---

## 🌊 Выбор настроения «Моей волны» прямо в интерфейсе

Выбирать настроение можно прямо во время воспроизведения в работающем плеере:

### В интерфейсе `cliamp` (по умолчанию):
- Нажмите **`W`** (Shift+W) в окне плеера — настроение автоматически переключится на следующее:
  `🔥 Бодрое` ➔ `☕ Спокойное` ➔ `😄 Весёлое` ➔ `🌧 Грустное` ➔ `❤️ Любимое` ➔ `✨ Незнакомое` ➔ `🎲 Любое`
- Плеер сразу отправляет запрос на сервер Яндекс Музыки и выводит уведомление с выбранным настроением.

### В автономном Python TUI (`yam-cliamp --py`):
- Нажмите клавишу **`W`** — прямо по центру экрана откроется интерактивное ретро-окно:
  ```text
  ╔═════════════════ НАСТРОЕНИЕ «МОЕЙ ВОЛНЫ» ═════════════════╗
  ║                                                           ║
  ║   [1]  🔥  Бодрое (энергичное)                            ║
  ║   [2]  ☕  Спокойное (релакс)                             ║
  ║   [3]  😄  Весёлое (радостное)                            ║
  ║   [4]  🌧  Грустное (меланхоличное)                       ║
  ║   [5]  ❤️  Любимое (треки из ваших лайков)                ║
  ║   [6]  ✨  Незнакомое (открытия и новинки)                ║
  ║   [7]  ⭐  Популярное (топовые хиты)                      ║
  ║   [8]  🎲  Любое (стандартный микс)                       ║
  ║                                                           ║
  ║   [↑/↓ / 1-8] Выбрать   [ENTER] Применить   [ESC] Отмена  ║
  ╚═══════════════════════════════════════════════════════════╝
  ```
- Перемещайтесь стрелками `[↑]` / `[↓]` (или нажмите цифру `1`-`8`) и нажмите **`[Enter]`** для мгновенного применения!

---

## ⌨️ Горячие клавиши

| Клавиша | Функция |
|---|---|
| **`W`** | **Выбор / смена настроения «Моей волны»** |
| **`S`** или **`Z`** | **Случайный порядок (Shuffle)** Вкл / Выкл |
| **`>`** или **`.`** (буква `Ю`) | **Следующий трек** (Вперёд) |
| **`<`** или **`,`** (буква `Б`) | **Предыдущий трек** (Назад) |
| **`[X]`** | Воспроизведение (Play) |
| **`[C]`** или **`[Пробел]`** | Пауза / Возобновить |
| **`[V]`** | Стоп |
| **`[→]` / `[←]`** | Перемотка ±5 секунд |
| **`[?]`** | Справка по всем клавишам |
| **`[Q]`** | Выход |
