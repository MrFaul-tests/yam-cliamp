## 📖 О проекте

**yam-cliamp** — это терминальный плеер и экосистема для прослушивания **Яндекс Музыки** прямо из консоли в ретро-эстетике Winamp 2.x.

Проект решает ключевые проблемы использования Яндекс Музыки в терминале:
1. **Автоматическая авторизация в 1 клик**: больше не нужно вручную вытаскивать и вставлять токены через консоль разработчика. yam-cliamp открывает окно браузера с официальным OAuth Яндекса (вход по QR-коду, телефону или паролю), перехватывает токен через Chrome DevTools Protocol (CDP) и автоматически закрывает браузер.
2. **Бесшовная интеграция с `cliamp`**: токен автоматически прописывается в конфигурацию официального плеера [cliamp](https://github.com/bjarneo/cliamp) (`~/.config/cliamp/config.toml`), запуская его с провайдером `--provider yandex`.
3. **«Моя волна» под контролем**: возможность на лету переключать настроение волны («Бодрое», «Спокойное», «Весёлое», «Грустное», «Любимое», «Незнакомое», «Lo-Fi» и др.) прямо во время воспроизведения клавишей `Shift+W` (`W`), через консольные флаги или через всплывающее меню.
4. **Два режима работы**:
   - 🚀 **Основной режим**: быстрый запуск мощного плеера `cliamp` (написанного на Go) с провайдером Яндекс Музыки.
   - 🦙 **Автономный Python TUI (`--py`)**: резервный легковесный ретро-плеер на `curses` + `mpv IPC`, работающий даже если `cliamp` не установлен в системе.

---

## ✨ Ключевые возможности

- 🎧 **«Моя волна» со всеми настроениями**: переключение настроений, характера (любимое, открытия, популярное) и языка.
- ☕ **Специальный режим Lo-Fi**: запуск волны фокуса и расслабления одной командой (`yam-cliamp --lofi`).
- 🔐 **Безопасность и локальность**: все токены хранятся исключительно на вашей машине в `~/.config/yam-cliamp/` и `~/.config/cliamp/`, без сторонних серверов.
- 🔀 **Бесконечный поток**: автоматическая непрерывная подгрузка следующих партий треков «Моей волны».
- ⌨️ **Поддержка раскладок**: горячие клавиши работают одинаково удобно как на английской (`W`, `Z`, `S`, `X`, `C`, `V`), так и на русской раскладке (`Ю`, `Б` и др.).
- 📊 **Ретро-интерфейс**: псевдографический Winamp 2.x, спектральный визуализатор и статус-бар.

## 🛠 Системные требования

- **ОС**: Linux или macOS
- **Python**: 3.10 или новее
- **mpv**: консольный аудиоплеер (`sudo pacman -S mpv` / `sudo apt install mpv`)
- **Chromium / Chrome / Brave**: браузер для разовой авторизации через CDP
- **cliamp** (рекомендуется): официальный терминальный плеер [cliamp](https://github.com/bjarneo/cliamp)

## 🚀 Установка и быстрый старт

### 1. Установка `cliamp`

Для работы плеера в основном режиме рекомендуется установить `cliamp`. Вы можете выбрать как модифицированный форк с расширенными возможностями «Моей волны», так и оригинальную версию:

#### Вариант А (Рекомендуется): Сборка пропатченного форка [MrFaul-tests/cliamp](https://github.com/MrFaul-tests/cliamp)
В этом форке на Go реализованы эксклюзивные улучшения для Яндекс Музыки:
- 🔄 **Переключение настроения волны на лету**: клавиша **`W`** (`Shift+W`) циклически меняет настроение прямо во время воспроизведения в TUI с показом уведомлений.
- ♾️ **Бесконечный непрерывный поток**: автоматическая догрузка рекомендаций волны пачками по 15 треков при приближении к концу списка.
- ☕ **Станция «Моя волна: Lo-Fi»**: поддержка чилл/фокус волны и флага `--playlist wave:lofi`.

Сборка из исходников (требуется Go 1.22+):
```bash
git clone https://github.com/MrFaul-tests/cliamp.git
cd cliamp
go build -o cliamp .
mkdir -p ~/.local/bin && mv cliamp ~/.local/bin/
```

#### Вариант Б: Установка официального upstream cliamp
Если вам достаточно стандартных возможностей:
- **Официальный скрипт (Linux / macOS)**:
  ```bash
  curl -fsSL https://cliamp.stream/install.sh | sh
  ```
- **Arch Linux (AUR)**:
  ```bash
  yay -S cliamp
  # или: paru -S cliamp
  ```
- **macOS / Linux (Homebrew)**:
  ```bash
  brew install bjarneo/cliamp/cliamp
  ```
- **Nix**:
  ```bash
  nix run github:bjarneo/cliamp
  ```

> 💡 **Подсказка:** Если `cliamp` не установлен в системе, `yam-cliamp` автоматически запустит встроенный резервный TUI-плеер на Python (`--py`), поэтому звук и воспроизведение будут работать в любом случае!

---

### 2. Клонирование репозитория yam-cliamp

```bash
git clone https://github.com/MrFaul-tests/yam-cliamp.git
cd yam-cliamp
```

### 3. Установка зависимостей Python

```bash
pip install -r requirements.txt
```

*(Зависимости: `yandex-music` и `websockets`)*

### 4. Создание команды запуска (симлинк)

```bash
mkdir -p ~/.local/bin
ln -s $(pwd)/main.py ~/.local/bin/yam-cliamp
chmod +x ~/.local/bin/yam-cliamp
```

Убедитесь, что `~/.local/bin` добавлен в переменную `$PATH` (обычно уже настроено в `.bashrc` / `.zshrc`).

## 🔑 Авторизация

При первом запуске `yam-cliamp` автоматически определит отсутствие токена и откроет окно браузера:

```bash
yam-cliamp
```

1. В появившемся окне авторизации подтвердите вход в Яндекс ID (удобнее всего нажать **«QR-код»** и отсканировать камерой смартфона из приложения Яндекс Музыка или Яндекс Go).
2. Сразу после успешного входа токен будет перехвачен, браузер автоматически закроется, а плеер начнёт воспроизведение.
3. Токен сохранится в `~/.config/yam-cliamp/config.json` и автоматически синхронизируется с `~/.config/cliamp/config.toml`.

Для принудительного повторного входа или смены аккаунта используйте:
```bash
yam-cliamp --auth
```

Проверить текущий статус авторизации:
```bash
yam-cliamp --status
```

## 🌊 Управление «Моей волной»

### 1. Переключение на лету в работающем плеере

- **В интерфейсе `cliamp` (по умолчанию)**:
  - Нажмите **`W`** (Shift+W) в окне плеера — настроение переключится на следующее по кругу:
    `🔥 Бодрое` ➔ `☕ Спокойное` ➔ `😄 Весёлое` ➔ `🌧 Грустное` ➔ `❤️ Любимое` ➔ `✨ Незнакомое` ➔ `🎲 Любое`
  - Плеер сразу обновляет поток рекомендаций и выводит всплывающее уведомление с выбранным настроением.

- **В автономном Python TUI (`yam-cliamp --py`)**:
  - Нажмите клавишу **`W`** — откроется интерактивное окно прямо поверх интерфейса:
    ```text
    ╔═════════════════ НАСТРОЕНИЕ «МОЕЙ ВОЛНЫ» ═════════════════╗
    ║                                                           ║
    ║   [1]  🔥  Бодрое (энергичное)                            ║
    ║   [2]  ☕  Спокойное (релакс)                             ║
    ║   [3]  😄  Весёлое (радостное)                            ║
    ║   [4]  🌧  Грустное (меланхоличное)                       ║
    ║   [5]  ❤️  Любимое (треки из ваших лайков)                ║
    ║   [6]  ✨  Незнакомое (открытия и новинки)                ║
    ║   [7]  ⭐  Популярное (топовые хиты)                      ║
    ║   [8]  🎲  Любое (стандартный микс)                       ║
    ║                                                           ║
    ║   [↑/↓ / 1-8] Выбрать   [ENTER] Применить   [ESC] Отмена  ║
    ╚═══════════════════════════════════════════════════════════╝
    ```
  - Выберите пункт стрелками `[↑]` / `[↓]` (или цифрой `1`–`8`) и нажмите **`[Enter]`**.

### 2. Запуск волны через флаги CLI

| Команда | Описание |
|---|---|
| `yam-cliamp --lofi` | Запуск волны **Lo-Fi** (чилл, фокус, биты) |
| `yam-cliamp --wave` | Интерактивный диалог настройки настроения, характера и языка перед стартом |
| `yam-cliamp --mood active` | Запуск с бодрым настроением (`active`, `fun`, `calm`, `sad`, `all`, `lofi`) |
| `yam-cliamp --character favorite` | Выбор характера треков (`favorite`, `discover`, `popular`, `default`) |
| `yam-cliamp --lang russian` | Фильтр языка (`any`, `russian`, `not-russian`) |

## ⌨️ Горячие клавиши

| Клавиша | Функция |
|---|---|
| **`W`** | **Выбор / смена настроения «Моей волны»** |
| **`S`** или **`Z`** | **Случайный порядок (Shuffle)** Вкл / Выкл |
| **`>`** или **`.`** (буква `Ю`) | **Следующий трек** (Вперёд) |
| **`<`** или **`,`** (буква `Б`) | **Предыдущий трек** (Назад) |
| **`[X]`** | Воспроизведение (Play) |
| **`[C]`** или **`[Пробел]`** | Пауза / Возобновить |
| **`[V]`** | Стоп |
| **`[→]` / `[←]`** | Перемотка ±5 секунд |
| **`[↑]` / `[↓]`** | Громкость (в TUI режиме) |
| **`[?]`** | Справка по всем клавишам |
| **`[Q]`** | Выход из программы |

## 🖥 Автозапуск и ярлык рабочего стола

Для добавления `yam-cliamp` в системное меню приложений или автозапуск создайте файл `~/.config/autostart/yam-cliamp.desktop` (или `~/.local/share/applications/yam-cliamp.desktop`):

```ini
[Desktop Entry]
Type=Application
Name=yam-cliamp
Comment=Терминальный ретро-плеер Яндекс Музыки
Exec=kitty --class yam-cliamp --title cliamp ~/.local/bin/yam-cliamp
Icon=cliamp
Terminal=false
Categories=Audio;Music;Player;AudioVideo;
```
*(Замените `kitty` на ваш любимый терминал: `alacritty`, `ghostty`, `foot` и т.д.)*

## 🔒 Конфиденциальность и безопасность

- **Никаких утечек**: Ваши пароли, данные учётной записи и токены никогда не покидают ваш компьютер.
- Авторизация происходит напрямую через официальные серверы `oauth.yandex.ru`.
- Токен авторизации хранится локально в правах доступа вашего пользователя (`~/.config/yam-cliamp/config.json`).
